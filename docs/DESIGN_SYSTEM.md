# Base de interface provisória
A Etapa 01 não define a identidade visual final. Layout estrutural simples, português do Brasil, tokens CSS semânticos, foco visível e navegação por teclado. Botão reutilizável baseado em Radix/CVA e configuração shadcn/ui.
Identidade, tipografia e painéis completos serão definidos na etapa visual correspondente.
